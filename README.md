# Missão BigTech — Algoritmos e Estruturas de Dados (DSA)


Repositório com códigos de referência, análises de complexidade e resoluções comentadas de Algoritmos e Estruturas de Dados (LeetCode e Codeforces).

O conteúdo está dividido em duas frentes:

## 1. YouTube — LeetCode Top Interview 150 (`youtube-top-interview-150/`)
Série aberta no canal [@RailtonCalheiros](https://www.youtube.com/channel/UCBE5X2uY5Ueap39bSeM9vWw/playlists) resolvendo os problemas clássicos da lista [**LeetCode Top Interview 150**](https://leetcode.com/studyplan/top-interview-150/), organizados pelos tópicos oficiais da lista.

Cada problema possui um arquivo `.md` com:
- Link para a solução em vídeo
- Ideia da solução
- Análise de complexidade (Tempo e Espaço)
- Implementações comentadas em **Python**, **Java** e **C++**

## 2. Curso Missão BigTech (`curso-missao-bigtech/`)
Códigos desenvolvidos nas aulas e resoluções de exercícios (LeetCode e Codeforces) do curso [**Missão BigTech**](https://missaobigtech.com.br/). Os arquivos seguem o mesmo padrão `.md` do YouTube
